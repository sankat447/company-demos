# EDA Rulebooks (AAP Discovery Path)

Files in this directory are copies of rulebooks from the demo solution at
`ropes-&-gray/code/aap/eda/rulebooks/`. AAP EDA requires rulebooks to be
at `extensions/eda/rulebooks/` relative to the repo root for automatic
discovery.

**Source of truth:** `ropes-&-gray/code/aap/eda/rulebooks/`

When updating rulebooks, edit the source in `ropes-&-gray/` and copy here.
