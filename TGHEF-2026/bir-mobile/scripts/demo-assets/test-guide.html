1 · Install the app

Android
  1. Uninstall any older “Bir” demo first (Settings → Apps → Bir → Uninstall), so this newer build installs cleanly.
  2. Open the download page and scan the Android QR, or tap Download APK.
  3. Open the downloaded file → when asked, allow “Install from this source” → Install.
  4. Open Bir Festival 2026.

पुराना डेमो पहले अनइंस्टॉल करें → QR स्कैन करें → फ़ाइल खोलें → “इस स्रोत से इंस्टॉल की अनुमति दें” → इंस्टॉल।

iPhone

Apple doesn’t allow direct installs — the iOS build comes via TestFlight. Send your Apple‑ID e‑mail to the delivery team for an invite. iPhone बिल्ड TestFlight से मिलेगा।

Tip — test offline too. Install and sign in once while online (loads the sample data), then switch on Airplane mode and confirm passes, the schedule, scanning and check‑in still work.

2 · Sign in & language

  1. Enter any 10‑digit number (e.g. 9876543210) → Continue.
  2. Enter OTP 123456.
  3. You land on Home with a “Demo / Evaluation build” banner and all roles unlocked.

Language: tap the EN / हिं pill on Home (top‑right) or More → Change Language. Please run tests in both English and Hindi and note any untranslated or clipped text.

Sign out: More → Sign Out. Signing back in with 123456 reuses the same sample data.

4 · What to test (area checklist)

Sign‑in

  • Any number + 123456 signs in; a clearly invalid number is refused; a wrong OTP is refused with a clear message.
  • Sign out → relaunch returns to sign‑in.

Home · fly‑status · SOS

  • Fly‑status chip shows Flying (green) with a reason.
  • SOS needs two taps — one tap asks to confirm; it must not fire on a single tap. Second tap shows “help sent”.
  • Language switch changes all Home text incl. the fly‑status reason.

Tickets

  • Tiers show Day pass ₹499 and 3‑Day pass ₹1199; selecting one shows the right amount.
  • Paying is blocked by design in this build — note the message.
  • Passes appear in My Pass with a QR that still opens in Airplane mode.

Cultural nights

  • Day tabs 21 / 22 / 23 Nov; events with venues (e.g. Folk music of Kangra).
  • Remind toggles a reminder; Vote works once on votable events and blocks a second vote.
  • Voting/reminders work in Airplane mode and sync later.

Highlights & My Registrations

  • Categories: Competitions, Cultural Nights, Yoga, Pottery, Adventure, Sightseeing.
  • Competitions include Himalayan Prince/Queen 2026; items show rules in English + Hindi.
  • Register for a free item → it appears in My Registrations with a status.
  • Adventure → Paragliding shows time slots (some full/waitlisted).
  • In My Registrations: Add to calendar opens the device calendar; Cancel works.

Volunteer

  • Roster: team, ID‑verified status, shifts across 21–23 Nov; Check In then Check Out (works offline).
  • Scanner: camera opens (grant permission); Kiosk mode keeps the screen awake; scanning a QR pass gives a verdict in ~1s — green = valid, red = invalid — and still works in Airplane mode (a “pending sync” count rises).
  • Report Incident: category + note + optional photo → queued with a confirmation.

Ops & fly‑status (Safety Officer)

  • More → Ops shows a live snapshot (fly‑status, unsynced scans, queued writes, lodging version).
  • Declare a reason in English + Hindi, tap Hold → Home chip changes to Hold and an auto‑refund notice appears. Set back to Flying to clear it.

Lodging & badges (Admin — Hospitality)

  • Rooms: inventory with status filter + hotel search; Add Room works.
  • Allocate: pool loads (e.g. Anita Thakur, Rohan Katoch); Auto‑suggest proposes rooms; an invalid move (over capacity / mixed‑gender share) is blocked with a reason in EN + HI; a valid placement commits.
  • Occupancy shows rooms by hotel with check‑in status.
Privacy check (important). Confirm gender is never shown on a badge, occupancy board or hotel roster — it may appear only on the Allocate screen. A badge shows initials + QR, no photo. Report any leak as Critical.

Partner

  • Stalls: stall name, stage, allocation, fee & paid/unpaid, daily footfall, food‑street rules (EN + HI).
  • Hospitality: guest rows with Check In; the occupancy count updates.

Language & offline sweep

  • Walk the main screens in Hindi — no leftover English, no clipped text.
  • With Airplane mode on: open a pass, view the schedule, scan, check in, vote — all should work; turning the network back on should sync pending items with nothing lost or duplicated.

5 · Known limits — please don’t log these as bugs

  • Payments are disabled — you can reach the pay step but not be charged.
  • The only working OTP is the demo code 123456 (any phone number).
  • All roles are visible at once — role‑by‑role gating is checked in a later round.
  • Names, rooms, stalls, shifts and competitions are sample data.
  • The AI Explore / Assistant is a placeholder.
  • Some server actions are simulated on the device for this self‑contained build.
  • Venue maps may not render (map key not shipped in the demo).

6 · Reporting a finding

For anything that doesn’t match “what to test”, capture:

  • The area / screen and what you tapped
  • Device & Android version, and the app version (from More)
  • Language (EN/HI) and whether you were online or in Airplane mode
  • Steps, Expected vs Actual, and a screenshot / screen‑recording
  • Severity — Critical (blocked / data loss / safety / privacy), Major (broken, has a workaround), Minor (cosmetic / copy)
